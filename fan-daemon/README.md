# Clevo fan daemon

This directory bundles the fan daemon for Clevo Control. It is based on
[hajilok/clevo-axioo-dual-fan-linux, v1.0.0](https://github.com/hajilok/clevo-axioo-dual-fan-linux/tree/v1.0.0),
itself a fork of [SkyLandTW/clevo-indicator](https://github.com/SkyLandTW/clevo-indicator).
It includes the local daemon fixes for persistent fan modes, adaptive polling,
asynchronous GUI access, and gradual fan cooldown.

The daemon is licensed under [GPL version 2](LICENSE). See the repository's
main README for installation and service commands.
